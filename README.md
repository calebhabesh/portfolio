# Caleb Habesh

My personal portfolio, with selected engineering projects and an interactive 3D lion emblem.

[Visit the portfolio](https://calebhabesh.com/)

Built with React, TypeScript, Vite, and Three.js.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

See [development notes](docs/development.md) for checks and the model workflow.
